# 22cav.github.io

My personal site, built with [Astro](https://astro.build). Live at <https://22cav.github.io>.

```sh
npm install
npm run dev            # http://localhost:4321, drafts visible
npm run ship "Message" # commit, push to `website`, deploy
```

- Posts: `src/content/blog/`
- Projects: `src/content/projects/<name>/`
- News and links: `src/data/site.ts`
