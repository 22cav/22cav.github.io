## The problem

Most research clusters use the Slurm scheduler. Checking on your jobs usually
means typing `squeue` again and again and reading through a wall of text.

## What I did

SlurmTerm is a full terminal interface for Slurm. It has:

- a live job queue you can search, with bulk cancel and hold;
- a job composer with a form, a live preview of the script, and help for every
  parameter;
- a view of the cluster's nodes and hardware;
- your job history.

It works with the keyboard, and with the mouse if you want. When you start an
interactive job, it steps aside and drops you into the session, then comes back
when you leave.

The first version was in Python. It was too slow to start, so I rewrote it in
Rust. Now it starts instantly and ships as a single binary with no
dependencies. You can copy it to any login node, which matters on clusters
where you can't install software.

## Install

```sh
cargo install slurm-term
# or
pip install slurm-term
```
